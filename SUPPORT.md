# Support - DokuReader

## Primärer Kanal

- GitHub Issues: <https://github.com/doc-bricks/DokuReader/issues>

## Wofür der Kanal gedacht ist

- reproduzierbare Fehlerberichte
- Vorschläge für Dokumentformate oder Companion-Workflows
- Rückfragen zu Windows-Build, Store-Readiness oder Exportformat

## Was in ein gutes Ticket gehört

- DokuReader-Version oder Commit-Stand
- Windows-Version
- betroffener Dokumenttyp (`.pdf`, `.txt`, `.docx`, `.odt`, Bild)
- kurze Repro-Schritte
- falls relevant: ob LibreOffice, Word, PyMuPDF oder `pdf2image` lokal installiert sind
