LEVEL 1 SBOM INVARIANT VALIDATION CONFIRMATION (Stand 2026-10-01):
- INV-LOCAL-01 (100% Local-First & Zero-Egress): PASS. Zero external telemetry; documents, state, outlines, and previews remain strictly local.
- INV-RUNAS-02 (Unprivileged User Mode & Non-Elevation): PASS. RunAsInvoker mode; standard user privileges without administrative elevation.
- INV-INPLACE-03 (In-Place File Safety): PASS. Original documents are strictly read-only; files are never modified, moved, or deleted.
- INV-SCHEMA-04 (Deterministic Schema): PASS. Library metadata exports adhere to versioned dokureader-library-v1 JSON specification.
- INV-ISOLATION-05 (State & Cache Isolation): PASS. Isolated local JSON state in ~/.dokubibliothek_state.json; scoped PWA cache.
- INV-SANDBOX-06 (Safe Subprocess Execution): PASS. Headless LibreOffice and Word COM bridges execute with strict timeout and directory bounds.
- INV-PARITY-07 (Tri-Platform Source Support): PASS. Core source runs across Windows, macOS, and Linux with cross-platform path handling.
- INV-A11Y-08 (Accessibility & Usability): PASS. Full keyboard accessibility, semantic names/roles/states, and readable color contrast.
- INV-DISCOVERY-09 (Multimodal Transparency): PASS. Full bilingual documentation (EN/DE), machine-readable llms.txt, dual Mermaid diagrams.
- INV-SLA-10 (48h Response & 5-Day Triage SLA): PASS. Binding vulnerability response SLA under SECURITY.md with dedicated security contact channels.
