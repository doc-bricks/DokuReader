1. EXECUTIVE SUMMARY & CORE POSITIONING
--------------------------------------------------------------------------------
DokuReader is an unprivileged, local-first desktop document library manager and
topic-based PDF bundling application engineered for privacy-conscious knowledge
workers, researchers, legal tech analysts, and autonomous AI coding agents.

Key Value Proposition:
- Original files stay strictly in-place (INV-INPLACE-03): original documents are
  never copied, moved, modified, or overwritten; only references and read states
  are indexed.
- 100% Offline & Zero Network Egress (INV-LOCAL-01): zero external server calls,
  no telemetry, no analytics, and no cloud dependencies.
- Dual Export Architecture: produces versioned, machine-readable
  dokureader-library-v1 JSON metadata exports and consolidated merged PDF bundles
  filtered deterministically by read/unread status.
- Mobile PWA Companion: provides an offline-first, installable Web companion
  (web_companion/) for browsing libraries and toggling read status on mobile
  devices without native app store friction.
- Unprivileged Execution (INV-RUNAS-02): operates purely in user mode under
  RunAsInvoker principles without requiring administrative elevation.

2. TARGET AUDIENCES & 4 CORE PERSONAS
--------------------------------------------------------------------------------
1. Legal Tech & Compliance Analysts:
   Corporate counsel, compliance auditors, and legal tech professionals managing
   sensitive discovery documents, contracts, and regulatory filings that legally
   prohibit cloud upload under GDPR, HIPAA, or strict confidentiality mandates.

2. Academic Researchers & Literature Curators:
   Scholars, scientists, and PhD candidates organizing thousands of journal preprints,
   conference papers, and technical whitepapers into thematic reading queues without
   altering existing directory hierarchies or syncing to proprietary cloud vaults.

3. Offline-First Knowledge Workers & Privacy Advocates:
   Engineers, journalists, investigative reporters, and privacy officers who demand
   deterministic desktop reading utilities with zero network egress, transparent local
   JSON state files (~/.dokubibliothek_state.json), and unprivileged execution.

4. AI Desktop Application Developers & Coding Agents:
   Autonomous coding agents (Claude Code, Gemini/Antigravity, Codex CLI) and tool
   builders leveraging structured dokureader-library-v1.json schemas for downstream
   document processing, automated triage, and metadata extraction.
