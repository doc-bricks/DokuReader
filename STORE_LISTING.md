## Deutsch (`de-DE`)

### Kurzbeschreibung (max 100 Zeichen)
Lokale Dokumentenbibliothek mit Vorschau, Lesestatus, Sammel-PDF und Companion-JSON-Abgleich.

### Beschreibung (max 10.000 Zeichen)
DokuReader ist eine lokale Desktop-App für persönliche Dokumentenbibliotheken, Forschungsablagen und PDF-Sammlungen. Die Anwendung organisiert Dokumente nach Themen, zeigt Vorschauen für Text, Bilder und PDFs an und speichert ausschließlich Verweise sowie Lesestatus. Die Originaldateien bleiben unverändert an ihrem Speicherort.

**Was DokuReader kann:**
- Themenbasierte Dokumentenbibliothek für Forschung, Verwaltung oder private Unterlagen
- Lesestatus direkt in der Bibliothek markieren und filtern
- Vorschau für Textdateien, Bilder, PDFs sowie DOCX- und ODT-Dokumente
- Sammel-PDF-Export für alle, gelesene oder ungelesene Dokumente
- Bidirektionaler JSON-Metadaten-Abgleich (`dokureader-library-v1.json`) für den Offline-Web/PWA-Companion (`JSON-Export…` und `Status importieren…`)
- Öffnen der Originaldatei per Doppelklick im Standardprogramm des Betriebssystems

**Warum DokuReader?**
- 100 % lokal statt Cloud: keine Upload-Pflicht, kein Konto und keine Server-Bindung
- Datenschutzfreundlich: Exporte enthalten niemals Dokumentinhalte
- Leichtgewichtig: unprivilegierte Desktop-App (`RunAsInvoker`) ohne Hintergrunddienste

**Lizenz- und Open-Source-Hinweis:**
DokuReader wird als kostenloses Open-Source-Paket unter AGPL-3.0 vorbereitet; eine Einreichung oder Veröffentlichung ist derzeit nicht belegt.

## English (`en-US`)

### Short Description (max 100 chars)
Local document library with previews, read tracking, bundle PDF export, and JSON status sync.

### Description (max 10,000 chars)
DokuReader is a local desktop application for personal document libraries, research folders, and PDF collections. It organizes files by topic, previews text, image, and PDF content, and stores only references plus read status. Original files stay untouched in their existing location.

**What DokuReader does:**
- Topic-based library for research, admin work, or personal records
- Read/unread tracking directly inside the library
- Preview for text files, images, PDFs, DOCX, and ODT documents
- Combined bundle PDF export for all, read, or unread documents
- Bidirectional `dokureader-library-v1.json` metadata export and read-status re-import for offline Web/PWA companion workflows
- Open the original file with a double-click in your default application

**Why DokuReader?**
- Local instead of cloud-first: zero data egress, no mandatory account, no server dependency
- Privacy-friendly: standard exports never embed document contents
- Lightweight: unprivileged desktop app (`RunAsInvoker`) with no background services

**License and open-source note:**
DokuReader is prepared as a free open-source release under AGPL-3.0; no Store submission or publication is verified yet.

DokuReader — локальное настольное приложение для организации личных библиотек документов, исследовательских папок и коллекций PDF.
