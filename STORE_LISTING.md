## Deutsch

### Kurzbeschreibung (max 100 Zeichen)
Lokale Dokumentenbibliothek mit Vorschau, Lesestatus, Sammel-PDF und JSON-Export.

### Beschreibung (max 10.000 Zeichen)
DokuReader ist eine lokale Desktop-App für persönliche Dokumentenbibliotheken, Forschungsablagen und PDF-Sammlungen. Die Anwendung organisiert Dokumente nach Themen, zeigt Vorschauen für Text, Bilder und PDFs an und speichert nur Verweise sowie Lesestatus. Die Originaldateien bleiben an ihrem Speicherort.

**Was DokuReader kann:**

- Themenbasierte Dokumentenbibliothek für Forschung, Verwaltung oder private Unterlagen
- Lesestatus direkt in der Bibliothek markieren
- Vorschau für Textdateien, Bilder, PDFs sowie DOCX- und ODT-Dokumente
- Sammel-PDF-Export für alle, gelesene oder ungelesene Dokumente
- JSON-Export als `dokureader-library-v1.json` für spätere Companion-Workflows
- Öffnen der Originaldatei per Doppelklick in der Standardanwendung
- Optionale Office-zu-PDF-Konvertierung über LibreOffice oder Microsoft Word

**Warum DokuReader?**

- Lokal statt Cloud: keine Upload-Pflicht und keine Server-Bindung
- Datenschutzfreundlich: Standardexporte enthalten keine Dokumentinhalte
- Leichtgewichtig: Tkinter-Desktop-App ohne komplexen Server-Stack
- Praktisch für Forschung und Wissensarbeit: Themen, Vorschau und Lesestatus an einem Ort

**Lizenz- und Open-Source-Hinweis**

DokuReader wird als kostenloser Open-Source-Release für den Windows Store vorbereitet; eine Einreichung oder Veröffentlichung ist derzeit nicht belegt. Das Projekt steht unter AGPL-3.0. Optionale PDF-Vorschau über PyMuPDF bleibt deshalb ebenfalls im AGPL-Kontext und ist in Repository, Privacy-Doku und Drittanbieter-Lizenzübersicht offengelegt.

## English

### Short Description (max 100 chars)
Local document library with previews, read tracking, bundle PDF export, and JSON export.

### Description (max 10,000 chars)
DokuReader is a local desktop application for personal document libraries, research folders, and PDF collections. It organizes files by topic, previews text, image, and PDF content, and stores only references plus read status. Original files stay in their existing location.

**What DokuReader does:**

- Topic-based library for research, admin work, or private records
- Read/unread tracking directly inside the library
- Preview for text files, images, PDFs, DOCX, and ODT documents
- Combined PDF export for all, read, or unread documents
- JSON export as `dokureader-library-v1.json` for later companion workflows
- Open the original file with a double-click in the default application
- Optional Office-to-PDF conversion through LibreOffice or Microsoft Word

**Why DokuReader?**

- Local instead of cloud-first: no upload requirement and no server dependency
- Privacy-friendly: standard exports never embed document contents
- Lightweight: Tkinter desktop app without a complex service stack
- Useful for research and knowledge work: topics, previews, and read tracking in one place

**License and open-source note**

DokuReader is being prepared as a free open-source Windows Store release; no submission or publication is verified yet. The project is licensed under AGPL-3.0. Optional PDF preview through PyMuPDF therefore remains within the AGPL context and is documented in the repository, privacy policy, and third-party license summary.
