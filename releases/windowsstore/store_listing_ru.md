Краткое описание:
Локальная библиотека документов с предпросмотром, статусом чтения, сборным PDF и JSON-обменом.

Описание:
DokuReader — локальное настольное приложение для личных библиотек документов, исследовательских архивов и коллекций PDF. Программа организует файлы по темам, отображает предпросмотр текста, изображений и PDF и сохраняет только ссылки и отметки о прочтении. Исходные файлы остаются неизменными на своих местах.

Ключевые возможности:
- Тематическая библиотека для научных работ, делопроизводства и личных материалов
- Переключение статуса «прочитано / не прочитано» прямо в списке документов
- Встроенный предпросмотр текста, изображений, PDF, DOCX и ODT
- Создание единого сборного PDF для всех, прочитанных или непрочитанных документов
- Двусторонняя синхронизация статуса чтения через JSON (dokureader-library-v1.json) с офлайн Web/PWA-компаньоном
- Открытие оригиналов двойным щелчком в системном приложении по умолчанию
- Быстрый поиск и сортировка по имени, типу и размеру файла

Приватность и автономная работа:
- 100% локально: без облака, обязательных учётных записей и передачи данных третьим лицам
- Защита конфиденциальности: метаданные содержат только пути и флаги прочтения без содержимого файлов
- Лёгкость и скорость: работа без прав администратора и фоновых служб
